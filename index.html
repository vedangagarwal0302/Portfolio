Phishing Email Investigation & Analysis

Why I Built It: To understand how threat actors deliver malware and credential-harvesting links via email vectors.

Objective: Parse email headers, uncover originating IP addresses, and evaluate attachment safety.

Tools Used: Message Header Analyzer, VirusTotal, CyberChef.

What I Did: Extracted raw headers, traced SMTP hops, checked sender reputation, and isolated embedded URLs.

Outcome: Successfully created an Incident Report mapping out indicators of compromise (IOCs) for security hardening.

Mini SOC Lab for Threat Detection

Why I Built It: To gain direct experience with Security Information and Event Management (SIEM) rules.

Objective: Detect brute-force login attempts against local test endpoints.

Tools Used: Splunk, VirtualBox, Windows Event Viewer.

What I Did: Configured log forwarding, generated simulated authentication failure traffic, and wrote custom query filters.

Outcome: Developed alert triggers capable of notifying analysts upon repeated login failures.
